# The Workday Coffee – Landing Page

Landing page for The Workday Coffee, a campus coffee shop, built as a team project for INEW 2330 – Module 7 (Class Project).

## Team
| Name | Roles |
|------|-------|
| Daniel Tzul | Content Strategist (Team Lead), Marketing & Promotions |
| Adriana Valencia Padilla | Content Designer, Menu & Product |
| Mukudzei Chisenwa | Content Developer, SEO & Digital Optimization |

## Project Plan

**Audience**
- Business professionals
- Coffee enthusiasts

**Brand**
- Name: The Workday Coffee
- Look: brown, beige, and wood tones with an aesthetic, warm feel

**Hero Section**
- Slogan, background image, and a "View Menu" button

**Menu Sections**
- Coffee
- Teas and non-caffeinated drinks
- Refreshers
- Food

**Promotions**
- Buy One Get One
- Sign up for the mobile app and get something free

**SEO Keywords**
- To be decided

## Deliverables
| Role | Deliverables |
|------|--------------|
| Content Strategist | Content strategy document, audience personas, content roadmap, final content approval checklist |
| Marketing & Promotions | Promotional campaign plan, campaign messaging and CTAs, audience-targeted messaging, content mapped to page sections, promo approval checklist |
| Content Designer | UX content guidelines, UI content map, microcopy library, UX content approval checklist |
| Menu & Product | Menu highlights copy for featured items |
| Content Developer | Hero, About, CTA, and footer copy, plus content revision notes |
| SEO & Digital Optimization | Keyword list, SEO plan, page title, meta description, alt text, SEO audit checklist |

Each person also submits their own role document in Word, with screenshots of the finished page.

## Files
- `template.html`: page structure and content
- `styles.css`: page styling

## How to Run
Clone the repo and open `index.html` in a browser.

## Git Workflow
- No direct commits to `main` after the starting files are in.
- One branch per section, named `feature/...`.
- Every change goes through a Pull Request, and a teammate reviews it before merging.
- Pull before you start working.
